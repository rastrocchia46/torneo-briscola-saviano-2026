# Torneo di Briscola a Coppie 2026

Sito pubblico collegato al Google Sheet ufficiale tramite Apps Script.

## Contenuti pubblicati

- Panoramica
- Calendario e risultati delle qualificazioni
- Classifica generale
- Spareggi decisivi per l’8° e il 24° posto
- Play-off, ottavi, quarti, semifinali e finale
- Regolamento ufficiale

La gestione amministrativa dei sorteggi non è pubblicata sul sito.

## Pubblicazione su GitHub Pages

1. Caricare nella radice del repository tutti i file e le cartelle di questo pacchetto.
2. Aprire `Settings` → `Pages`.
3. In `Build and deployment`, scegliere `Deploy from a branch`.
4. Selezionare il branch `main` e la cartella `/ (root)`.
5. Salvare e attendere la pubblicazione.

## Endpoint dati

L’indirizzo Apps Script è configurato nel file `site-config.js`.
